Install

Running in under a minute

1

Download the extension

Grab the latest zip from the GitHub repository and unzip it to a folder you'll keep.

2

Open Chrome's extensions page

Go to chrome://extensions/ and switch on Developer mode (top right).

3

Load it

Click Load unpacked and select the unzipped folder — the one containing manifest.json.

4

Open a video

Head to any YouTube video and click the extension icon. The dashboard slides in from the right.

Works in Chrome and other Chromium browsers (Edge, Brave). No build step and no dependencies.

Process any video with any AI

You don't need the extension — or any API key — to get value out of this. Grab the transcript of any video, paste one of these prompts into ChatGPT, Claude, Gemini or a local model, and paste the transcript after it. Three jobs, three prompts.

Mode 1

📌 Chapters

A clean chapter list with a start time and a short, specific title for each segment.

Prompt
You are an expert video editor. I will give you a transcript whose lines already carry timestamps. Produce a chapter list.

Rules:
- Each chapter = a start timestamp + a short, specific title (3-7 words) naming the topic covered from that timestamp until the next chapter begins.
- Break only at genuine conceptual boundaries: a new idea, definition, sub-topic, method, worked example, or a shift from theory to practice. Not at every pause.
- Merge or drop filler (greetings, intros, sponsor reads, recaps); fold short remarks into the nearest real chapter.
- Use the start timestamp of the FIRST line of that segment.
- Use only timestamps that actually appear in the transcript. Never estimate, round or invent one.
- Format timestamps as MM:SS (use HH:MM:SS only if the video runs over an hour). Never write 04:46:00.
- Keep titles in the transcript's language. Aim for about 8-20 chapters on a 20-60 minute video - do not over-segment.

Output: a list like
- 00:00:12 - Introduction and scope of the theory
- 00:02:40 - Core definitions

Then add, under clear headings: a one-line summary per chapter; the key terms or definitions introduced; a tag per chapter ([Concept] / [Example] / [Derivation] / [Recap]); and the 3 chapters most important for revision.

Mode 2

🚫 SponsorBlock segments

Every part worth skipping, labelled and merged into clean intervals.

Prompt
Act as an expert educational video editor and SponsorBlock segment-extraction specialist. From the timestamped transcript below, find every portion that should be REMOVED or SKIPPED and label it with exactly one category:

- SPONSOR - paid promotions, product placements, brand mentions.
- SELFPROMO - channel merch, memberships, paid courses, social links.
- INTERACTION - asking to like, subscribe, follow, comment, ring the bell.
- INTRO - non-educational opener, channel bumper, greeting chatter.
- OUTRO - end credits, thank-yous, goodbye cards.
- FILLER - off-topic tangents, long chit-chat, technical difficulties.

Rules:
- Work only on removable-segment extraction. Do not output chapters or question timestamps.
- Merging: if two or more removable segments run back-to-back (one ends as the next begins, or with only a few seconds between), merge them into ONE continuous segment from the start of the first to the end of the last, even across different categories. Give the merged segment the dominant category by priority: SPONSOR > SELFPROMO > INTERACTION > INTRO > OUTRO > FILLER.
- In the Reason column, name the merged elements (e.g. "Intro + Sponsor").
- Use only timestamps that appear in the transcript. Format MM:SS (HH:MM:SS only if over an hour).

Output this table:

| # | Start | End | Category | Reason |
| - | ----- | --- | -------- | ------ |
| 1 | 01:15 | 02:40 | SPONSOR | Intro + Product promotion |

Then immediately after, the automation output - only the merged intervals and dominant category, one per line:
[MM:SS]-[MM:SS] CATEGORY

If nothing is removable, return only: NO REMOVABLE SEGMENTS FOUND

<paste the transcript here>
[01:15]-[02:40] SPONSOR [06:02]-[06:20] INTERACTION
Mode 3

🎯 MCQ / question timestamps

For exam-prep videos: index every question, its answer reveal and its explanation.

Prompt
Act as a high-precision MCQ timestamp extractor. From the timestamped transcript below, find every distinct multiple-choice question, problem-solving item, or question discussion and return its timestamps.

For each question, kept in video order, capture:
- Question Start - where the question begins.
- Correct Option Timestamp - where the correct option is revealed or highlighted, or N/A.
- Answer Start - where the detailed solution or explanation begins, or N/A.
- Correct Option - a single letter (A, B, C, D) or Unclear.

Rules:
- Use only timestamps that appear in the transcript. Never guess.
- If a timestamp is missing write N/A; if the option is unstated write Unclear.
- Ignore rhetorical questions and follow-up chatter - only genuine exam questions count.

Output ONLY this table - no preamble, no code fences:

| Q# | Question Start | Correct Option Timestamp | Answer Start | Correct Option |
| -- | -------------- | ------------------------ | ------------ | -------------- |
| Q1 | 04:46          | 06:54                    | 05:07        | B              |

How to get a transcript

From YouTube

Open the video → … More under the title → Show transcript. Click the transcript panel, select all, and copy. It already carries timestamps.

With the extension

Install it, open a video, and press 📜 Get transcript in the Editor tab. It fills the transcript in for you, ready to copy.

The full skill, with all three prompts, is in the repo at docs/toolkit/.

FAQ

Good to know

Is it free?
The extension is free and open source (MIT, with attribution). You bring your own AI key. And the prompt toolkit in the section above works with any free chatbot, no key at all.
Do I need an API key?
Only if you want the in-extension AI to write chapters automatically. You can also paste timestamps by hand, load chapters from a video's description, or use the toolkit prompts in an external chatbot.
Where is my data stored?
Settings, keys and cached chapters live in Chrome's local storage on your machine. Cloud sync to your Turso database is optional and off until you add your own database URL.
Does it work on Shorts or live streams?
It's designed for normal watch pages where a transcript exists. Shorts and live streams usually have no transcript, so there's nothing to analyse.
Which browsers are supported?
Chrome and Chromium-based browsers (Edge, Brave) on desktop, plus mobile YouTube pages in browsers that support extensions.
